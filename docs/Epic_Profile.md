# Кристина Костенко, Profile

1. Верстка экранов (UI)
    1.1. Верстка главного экрана профиля (аватар, описание, меню переходов). — 5–7 ч.
    1.2. Верстка модального экрана редактирования профиля со всеми текстовыми полями. — 6–8 ч
    1.3. Верстка списков «Мои NFT» (List) и «Избранные NFT» (LazyVGrid) с экранами-заглушками. — 8–10 ч.

2. Навигация и бизнес-логика
    2.1. Настройка навигации между экранами и интеграция встроенного браузера для сайта пользователя. — 5–7 ч.
    2.2. Реализация логики редактирования профиля и переключения кнопки «Избранное» в UI. — 6–8 ч.
    2.3. Реализация логики сортировки (по цене, рейтингу, названию) с сохранением настроек. — 5–7 ч.

3. Сеть и интеграция
    3.1. Создание моделей данных и сетевого сервиса (actor) для загрузки профиля и NFT. — 6–8 ч.
    3.2. Написание асинхронных запросов (async/await) и их связывание с UI через @MainActor. — 6–8 ч.
    3.3. Код-ревью, решение конфликтов слияния и финальный мерж эпика в общую ветку. — 4–6 ч.
