# FakeNFT

**FakeNFT** — учебное iOS-приложение для просмотра NFT-коллекций, управления избранным и корзиной, а также изучения пользовательских рейтингов.

Приложение позволяет знакомиться с NFT, просматривать информацию о коллекциях и пользователях, управлять собственным профилем и имитировать покупку NFT. Взаимодействие с данными и процесс оплаты реализуются с использованием mock-сервера.

Проект разрабатывался в команде в рамках дипломной работы на курсе iOS-разработки Яндекс Практикума.

## 🛠 Технологический стек

- **Язык:** Swift
- **UI:** SwiftUI
- **Архитектура:** MVVM
- **Работа с сетью:** REST API, mock-сервер
- **Асинхронность:** Swift Concurrency (async/await)
- **Многопоточность:** actor, @MainActor
- **Минимальная версия iOS:** 17.0
- **Контроль версий:** Git, GitHub

## 📱 Функциональность приложения

### Каталог NFT
- Просмотр каталога коллекций NFT.
- Отображение информации о коллекции: обложка, название, описание и автор.
- Просмотр NFT с изображениями, рейтингом и стоимостью в ETH.
- Сортировка коллекций.
- Добавление NFT в избранное и корзину.

### Корзина
- Просмотр добавленных NFT и их общей стоимости.
- Удаление товаров с подтверждением действия.
- Сортировка содержимого корзины.
- Выбор валюты и имитация оплаты через mock-сервер.
- Обработка успешных и неуспешных операций оплаты.

### Профиль пользователя
- Отображение фотографии, имени, описания и сайта пользователя.
- Редактирование персональных данных.
- Переходы к разделам «Мои NFT» и «Избранные NFT».
- Просмотр NFT пользователя и избранных NFT.
- Отображение пустых состояний при отсутствии данных.

### Рейтинг пользователей
- Просмотр рейтинга пользователей по количеству NFT.
- Сортировка пользователей.
- Просмотр информации о пользователе и его NFT-коллекции.

## 👩‍💻 Мой вклад в проект

В рамках командной разработки отвечала за реализацию модуля **«Профиль»**.

- Разработала интерфейс экрана профиля на SwiftUI с отображением пользовательской информации.
- Реализовала экран редактирования профиля с полями ввода, диалоговыми окнами и управлением состоянием интерфейса.
- Настроила навигацию между экраном профиля и разделами «Мои NFT» и «Избранные NFT».
- Работала с отображением данных профиля, состояниями загрузки и пользовательскими действиями.
